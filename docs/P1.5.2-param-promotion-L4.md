# P1.5.2 — Param promotion · Level-4 design

> **Companion to `PLAN.md`.** Lets a unit expose configuration (params) to be set per
> use — turning one composite into a *family* (`MultiplyBy2`, `MultiplyBy3`, …).
> **Pre:** P1.5.1, the encoder. **Inv:** I4 (derive-then-freeze), I5 (hash = identity),
> I8 (derived, not asserted). **Effort:** M. **Touches the canonical encoder** — the first
> such change since the foundations, hence this pass.

---

## 0. The decision that matters: instantiate-time, not eval-time

An "open" param can mean two operationally different things. The L3 sketch said *"the
evaluator injects supplied params into open slots"* (eval-time). Descending the leaf
argues the other way:

**(A) eval-time injection** — `eval(template, inputs, param_values)` fills open slots
during evaluation. The template keeps one hash; param values are runtime.

**(B) instantiate-time specialization (recommended)** — `instantiate(template, bindings)`
fills the open params and produces a **new, concrete, content-addressed `Unit`** (re-hashed
bottom-up); then it is evaluated like any other unit.

**(B) wins for this system:**
- **`eval` stays pure and concrete** — no second "param channel" in the evaluator; it only
  ever sees fully-frozen units (a template evaluates to `None`).
- **Instances are first-class units** — `MultiplyBy5` has a hash; it is shareable,
  inspectable, and **memoizable by hash for free** (the cache, P3.3, needs no param-aware
  key). This is the marketplace/cache payoff.
- **Same derive-then-freeze shape** as encapsulation — `instantiate` *is* a freeze.
- **"The param is part of identity" stays true** — `MultiplyBy5 ≠ MultiplyBy3` by hash.

(A) and (B) compute the *same result*; (B) merely persists the instance. So the core offers
`instantiate → Unit`; persisting-or-not is the caller's choice (a throwaway store for a
slider sweep, a real store for a saved unit). Eval-time injection, if ever wanted, is then a
pure editor-side optimization — not a core mechanism.

## 1. Representation — open params live in params; binding is by name

```rust
pub enum Param {
    Frozen { name: String, value: String },
    Open   { name: String },        // a hole, filled at instantiate time
}
```

- A param that is `Open(name)` is a **hole**. A unit with any open param in its closure is a
  **template** (a non-evaluable constructor).
- **Binding is by name, not a table.** A child's `Open("K")` is filled by the binding for
  `"K"`. No separate binding-table field on the composite — the name *is* the binding. (This
  is what replaces the L3 "binding table.")
- A unit's **open-param interface is derived, not stored** (I8): `open_params(unit) =` the
  set of `Open` names across its closure (union over children, recursively) — exactly like
  kind. The composite's `params` field stays empty; the interface is computed.

So "promotion" is automatic: encapsulate a selection that contains a template child, and the
composite exposes that open param by derivation. Making a param open is the trigger
(`open_param`, §3); the rest falls out.

---

## 2. The encoder change (the sensitive part)

`Param` gains a one-byte **variant tag** in the preimage: `0x00` Frozen `‖ name ‖ value`;
`0x01` Open `‖ name`. Domain-separated, length-prefixed, like the rest. Consequences:
- A `Frozen` and an `Open` param with the same name **hash differently** (correct — they are
  different).
- Adding the tag changes the preimage of **every param-bearing unit**, so their hashes
  change. **Pre-release ⇒ no migration**; the `ENCODING_VERSION` byte already covers the
  evolution (note it, optionally bump to 2).
- Existing tests are *relative* (determinism, "param value changes hash", equal-vs-not), so
  they keep passing under the new encoding — but this is the one inch where the encoder's
  determinism/domain-separation rules must be honored exactly.

## 3. Operations

```rust
// Frozen → Open: make a param a hole (creates/extends a template). The inverse of binding.
pub fn open_param(unit: &Unit, param: &str, open_name: &str) -> Result<Unit, ParamError>;

// the derived open-param interface (union of Open names over the closure)
pub fn open_params(unit: &Unit, resolver: &impl Resolver) -> BTreeSet<String>;

// Open → Frozen: specialize. Substitute the given bindings throughout the closure,
// re-hash bottom-up, insert new concrete units, return the top hash. Partial binding is
// allowed (unprovided names stay open ⇒ result is still a template).
pub fn instantiate(
    template: &Hash,
    bindings: &BTreeMap<String, String>,
    store: &mut MapResolver,
) -> Result<Hash, ParamError>;
```

`instantiate` recursion: a child is rebuilt only if its closure contains a *bound* open name;
otherwise it is referenced **unchanged** (its hash is stable). A rebuilt unit substitutes
`Open(n)→Frozen(n, bindings[n])` in its own params and points at any rebuilt children, then
is inserted (content-addressing dedups identical instances).

`eval` is unchanged: a template has an `Open` param a primitive can't compute, so it yields
`None` — templates are simply not evaluable until instantiated.

## 4. Sub-leaves (build order)

| # | sub-leaf | gist | touches |
|---|---|---|---|
| a | `Param = Frozen \| Open` + encoder tag | the representation + the one-byte preimage tag | **encoder** |
| b | `open_param` + `open_params` | make a hole; derive the open interface | — |
| c | `instantiate` | specialize bottom-up, re-hash, insert | resolver(store) |

`compute` must also read a value only from `Frozen` params (an `Open` constant ⇒ `None`).

---

## 5. Tests (the proofs)

- **Round-trip:** `open_param` a `number(5)` → template; `instantiate(K=5)` → a unit whose
  hash **equals** the original `number(5)`. Open-then-bind is identity.
- **Family by hash:** `instantiate(K=2)` and `instantiate(K=3)` of one template are
  **different units** (different hashes) and evaluate to different results.
- **Derived interface:** `open_params` of a composite wrapping a `number(Open "K")` child is
  `{"K"}` — derived, not stored.
- **Templates aren't evaluable:** `eval` of a template (open param present) is `None`;
  after `instantiate`, it computes.
- **Partial instantiation:** binding a subset leaves the rest open (still a template).
- **Encoder discipline:** a `Frozen` and an `Open` param of the same name hash differently;
  determinism preserved.

---

## 6. Deferred forks (recorded)

- **Composite-level open params** (a hole not tied to any child param) — not needed for
  promotion; open params live in (primitive) children, the interface is derived. Can be
  added later if a use appears.
- **Type of an open param** — params are stringly-typed today; an `Open` param has no type
  discipline. Param typing is a later refinement.
- **Eval-time injection (A)** — recorded as a possible *editor-side* optimization for rapid
  param sweeps; not a core mechanism.
